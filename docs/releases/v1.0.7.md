AULA SC680 macOS 설정 프로그램 **v1.0.7 (build 8)**

지원 환경: **Apple Silicon(M1 이상), macOS 13 이상**

설치: 기존 앱을 종료하고 DMG의 **SC680Config**를 **Applications** 폴더로 옮겨 교체해주세요. ZIP은 동일한 앱의 압축본입니다.

변경 사항:
- 8K 수신기의 대표 Usage Page만 검사해 설정 인터페이스를 누락하던 문제 수정. 전체 HID 컬렉션과 Output/Feature 보고서 정보를 확인합니다.
- 실제 열기 시도 없이 일반 오류 `0xE00002BC`를 “열기 차단”으로 표시하던 문제 수정
- 실제 권한 거부·다른 앱의 독점 사용·설정 보고서 누락을 구분하여 안내
- 마우스 입력을 가로채는 독점 열기 시도 제거. 공유 연결을 사용합니다.
- 별도 Feature unlock 인터페이스를 우선 선택하고 같은 수신기의 인터페이스만 함께 사용
- **Copy Connection Details** 버튼 추가: 인식 실패 시 연결 방식과 보고서 정보를 복사하여 진단할 수 있습니다.

사용: 8K 2.4GHz USB 수신기를 연결한 뒤 **Rescan**을 누르세요. 실제 권한 거부가 표시될 경우 **시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링**에서 SC680Config를 허용한 뒤 앱을 완전히 종료하고 다시 실행해주세요. 계속 실패하면 **Copy Connection Details**로 복사한 내용을 공유해주세요.

검증: macOS Release 빌드와 회귀 테스트(복합 HID 인터페이스 선택, 오류 분류, 기존 패킷·설정 보존), arm64 아키텍처·앱 서명·DMG·ZIP·SHA-256 검사. 실물 수신기 연결과 설정 반영은 사용자 환경에서 추가 확인이 필요합니다.

앱은 ad-hoc 서명이며 Apple 공증은 적용되지 않았습니다. macOS가 실행을 차단하면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기(Open Anyway)**에서 허용해주세요. 조명은 펌웨어에 따라 지원되지 않을 수 있으며 LOD·절전 시간·Move Wake·매크로 재생은 기기 적용을 지원하지 않습니다.

첨부된 `SHA256SUMS`로 다운로드 파일을 확인할 수 있습니다.
