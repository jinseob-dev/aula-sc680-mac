# SC680Config 1.0.12 (build 13)

- Fix misplaced sidebar menus and battery information by using one fixed-width sidebar beside the settings pane.
- Keep the Apply button readable when status messages are long. Use one Apply control above the current settings page.
- Label the DPI stage selected in the editor as Selected; this is not hardware readback of the active stage.
- Check rendered sidebar/detail alignment and Apply button bounds at minimum, wide, and tall window sizes, alongside the existing Apply rendering checks.
- Add SC680-Windows-Capture.zip: a portable logging proxy that runs a temporary copy of the installed Windows OEM app. The package contains no proprietary OEM binaries. Automated Windows tests verify all 12 exports forward arguments/results and preserve/log all 65 bytes.

## Known device limitations

The 8K receiver's full DPI/polling/buttons/attributes readback remains unavailable. DPI colors were observed to update after cycling the physical DPI button; immediate application is **not fixed in this release**. The user confirmed Windows OEM Apply updates immediately. A normal OEM Apply capture is needed to compare the exact command sequence; a conditional profile initialization command is not sent speculatively.

## Downloads

Use the arm64 DMG for Apple Silicon Macs. For the Windows comparison, extract SC680-Windows-Capture.zip, run capture.cmd, select the installed OEM Mouse.exe, change only the current stage's color and click Apply once, then exit the OEM app completely. Share only the resulting sc680_hid_capture.log and metadata.txt.
