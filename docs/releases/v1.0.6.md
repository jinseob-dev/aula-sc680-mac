AULA SC680 macOS 설정 프로그램 **v1.0.6 (build 7)**

지원 환경: **Apple Silicon(M1 이상), macOS 13 이상**

설치: 아래 DMG 파일을 열고 **SC680Config**를 **Applications** 폴더로 옮겨주세요. ZIP 파일은 동일한 앱의 압축본입니다. 기존 앱은 종료한 뒤 교체해주세요.

변경 사항:
- Middle(휠 클릭) 설정이 덮어써지던 문제와 Rescan 후 Forward/Back이 바뀌던 문제 수정
- DPI 단계의 활성화 상태와 RGB 색상을 기기에서 읽고 다시 적용할 때 보존
- 적용 후 읽기 결과가 다르거나 확인할 수 없을 때 경고를 유지
- 알 수 없는 버튼 기능과 변경하지 않은 버튼 파라미터·슬롯 보존
- 잘못된 프로필의 배열·인덱스·값을 검증하여 앱 종료 방지
- HID 통신과 재연결 대기를 별도 큐에서 처리하고 중복 적용 차단
- LOD, 절전 시간, Move Wake, 매크로 재생의 미구현 상태를 명확하게 표시

검증: macOS Release 빌드, Windows 캡처 패킷 기반 회귀 테스트, 모의 기기 테스트, arm64 아키텍처·앱 서명·DMG·ZIP·SHA-256 검사.

실물 SC680에서 실제 설정 반영과 전원 재시작 후 유지 여부는 아직 확인이 필요합니다. 조명 효과는 펌웨어에 따라 지원되지 않을 수 있으며 확인되지 않은 상태로 표시됩니다. LOD·절전 시간·Move Wake는 로컬 프로필에만 저장됩니다.

기존 버전과 같이 앱은 ad-hoc 서명이며 Apple 공증은 적용되지 않았습니다. macOS가 실행을 차단하면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기(Open Anyway)**에서 허용해주세요.

첨부된 `SHA256SUMS`로 다운로드 파일의 SHA-256 값을 확인할 수 있습니다.
