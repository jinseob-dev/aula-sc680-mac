- `03 10 40 01 63`을 배터리 **99%**로 표시하며, 전체 설정 읽기와 구분합니다.
- 충전 이벤트는 충전 중으로 표시하고, 측정하지 않은 배터리 100%를 만들지 않습니다.
- 전체 Apply에서 미지원 Attributes·Light와 읽지 못한 Buttons를 명시적으로 건너뜁니다.
- 로컬 명령 검증 실패로 불필요하게 재연결하면서 진단 정보가 지워지는 문제를 수정합니다.
- Copy Connection Details는 최신 이벤트·출력 API 결과를 조회한 뒤 복사합니다.

배터리는 Rescan·Apply·Copy Connection Details 때 최신 수신 이벤트를 반영합니다.
DPI·폴링·속성·버튼 설정 전체 읽기와 변경·저장 여부는 아직 실물 확인이 필요합니다.
