AULA SC680 macOS 설정 프로그램 **v1.0.8 (build 9)**

지원 환경: **Apple Silicon(M1 이상), macOS 13 이상**

설치: 기존 앱을 종료한 뒤 DMG의 **SC680Config**를 **Applications** 폴더로 옮겨 교체해주세요. ZIP은 동일한 앱의 압축본입니다.

이번 버전은 v1.0.7에서 수신기는 연결되지만 Battery·DPI·Polling·Attributes·Buttons를 읽지 못하는 경우를 위한 응답 처리 및 진단 개선입니다.

변경 사항:
- 제어 요청(GET_REPORT) 외에 비동기 **Input 0x04** 보고서를 받는 경로 추가. 수신기 설명자에 해당 Input 보고서가 있을 때 사용합니다.
- 재연결·출력 전송 이전의 오래된 응답, 다른 설정의 응답, 잘못된 체크섬을 읽기 확인에 사용하지 않도록 검증
- **Copy Connection Details**에 Input 보고서 ID·크기, 설정 인터페이스의 원본 HID 설명자, 실제 읽기 오류 코드와 제한된 제조사 응답 정보를 추가
- Feature 보고서가 없는 수신기에 존재하지 않는 Feature 읽기 시도를 생략
- 복사 정보에 Rescan·Apply 이후 통신 결과를 반영

확인 방법: 수신기를 연결하고 **Rescan**을 누르세요. 여전히 읽기에 실패하면 **Copy Connection Details**로 복사한 내용을 공유해주세요.

실물 로그에서는 Output 0x04 연결 성공과 Feature 보고서 부재를 확인했습니다. 비동기 수신으로 읽기가 가능한지와 정확한 8K 읽기 요청 형식은 아직 실물 검증이 필요합니다. 확인되지 않은 읽기 명령을 보내거나 읽기 실패를 성공으로 표시하지 않습니다. 현재 값을 읽을 수 없으면 버튼 적용은 기존 설정 보존을 위해 중단됩니다.

검증: macOS Release 빌드, 비동기 응답 분류·시점·체크섬·큐 제한 및 기존 회귀 테스트, arm64·앱 서명·DMG·ZIP·SHA-256 검사.

앱은 ad-hoc 서명이며 Apple 공증은 적용되지 않았습니다. 조명은 펌웨어에 따라 지원되지 않을 수 있으며 LOD·절전 시간·Move Wake·매크로 재생은 기기 적용을 지원하지 않습니다.
