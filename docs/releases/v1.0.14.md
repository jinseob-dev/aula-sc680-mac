# SC680Config 1.0.14 (build 15)

- Listen for OEM Input report 0x03 / event 0x1010 and immediately show the DPI stage reported by the mouse. Previously only power telemetry was decoded, and the DPI page stayed on the local selection after a physical DPI button press.
- Show Mouse: Stage N and a mouse icon on the corresponding row. Follow hardware stage changes in the editor unless a manually selected stage is waiting for Apply.
- Preserve edited DPI values/colors and enabled stages. The event reports only the active stage; it does not provide the numeric DPI or a settings table.
- Clear the observed stage on rescan/disconnect and include it in copied diagnostics. No polling, settings queries or USB writes are added for synchronization.
- Regression coverage: report-ID/payload variants, invalid event codes/stages, passive device-to-model updates, draft preservation and disconnect handling; existing rendered UI checks remain required.

## Verification

Press the physical DPI button while the DPI page is open. Mouse: Stage N should change without Rescan. A separate Selected marker indicates an unapplied manual choice. If the stage is not present in the local enabled draft, the hardware marker still updates without changing the draft.

Full 8K settings readback remains unavailable. Live events do not verify edited numeric DPI/color values or resolve stage-color refresh timing. The event mapping comes from the manufacturer's Mouse.exe handler; physical macOS verification is still needed.
