# 1.0.15

Light now provides mode, brightness and speed without a separate color picker. Steady and Breathe use the receiver’s DPI-linked lighting modes and the DPI stage colors. Existing fixed-color profile fields remain readable but are no longer used to send lighting colors. Neon and Cycle Breathe retain automatic firmware color effects.

Apply DPI also refreshes lighting when an imported OEM baseline is available, preserving the shared mouse attributes. Physical stage synchronization remains passive; the receiver handles stage-linked colors.

Validation: macOS build, protocol/model regression tests and UI rendering checks run in GitHub Actions. Physical behavior still requires confirmation on the receiver.
