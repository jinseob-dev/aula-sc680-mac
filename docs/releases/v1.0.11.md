AULA SC680 macOS 설정 프로그램 **v1.0.11 (build 12)**

Apple Silicon, macOS 13 이상. 기존 앱을 종료한 뒤 앱을 Applications 폴더로 옮겨 교체하세요.

Apply 후 창이 비어 보인다는 실물 보고를 받아 화면 구조를 안정화했습니다.
- macOS 전용 분할 화면 사용, 선택 상태 유지 및 선택 페이지의 화면 식별자 고정
- 상단 상태 메시지를 최대 3줄로 제한하고 설정 영역의 공간 확보
- 상단 Apply는 **현재 페이지에만 적용** (DPI 페이지에서는 Apply DPI)
- 전체 적용은 Device 메뉴의 Apply All에서 실행
- Device 메뉴에도 Copy Connection Details 추가 (⌘⇧D); 긴 상태 전체와 통신 진단은 복사 내용에 포함

검증: macOS Release 빌드·기존 회귀 테스트, 실제 SwiftUI/AppKit 화면 렌더링 테스트
(DPI 단독 Apply·전체 Apply·매우 긴 상태 메시지 이후 설정 영역 표시), 설치 파일·서명·SHA-256 검사.
렌더링 검사는 CI의 macOS 14에서 수행합니다. 보고된 macOS 27 환경의 빈 화면은 직접 재현하지 못했으므로
이 버전에서 재발하는지 확인이 필요합니다. 전체 기기 설정 읽기는 아직 해결되지 않았습니다.

실물에서 DPI 색 변경이 반영되는 것은 확인했으나, 현재 단계 색의 즉시 갱신과 DPI 속도 변경·저장 여부는
추가 확인이 필요합니다. 앱은 ad-hoc 서명이며 Apple 공증은 없습니다.
