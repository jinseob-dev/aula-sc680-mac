# Windows 8K Apply capture

이 도구는 Windows 제조사 프로그램의 USB 호출을 기록합니다. 직접 설정 명령을 만들거나 변경하지 않습니다. 원본 설치 폴더는 그대로 두고 임시 복사본을 실행합니다.

1. ZIP 전체를 Windows에서 압축 해제합니다.
2. 기존 AULA 프로그램을 트레이 아이콘까지 종료합니다. 8K 수신기는 연결해 둡니다.
3. `capture.cmd`를 실행하고, 설치된 제조사 프로그램 폴더의 `Mouse.exe`를 선택합니다. 관리자 권한은 필요 없습니다.
4. 실행된 제조사 프로그램에서 **현재 DPI 단계의 색만** 바꾸고 Apply를 한 번 누릅니다. 마우스 DPI 버튼은 누르지 않습니다.
5. 색이 바로 바뀌는지 확인하고 제조사 프로그램을 트레이까지 종료합니다.
6. 자동으로 열린 결과 폴더의 `sc680_hid_capture.log`와 `metadata.txt`를 이 채팅에 첨부합니다. 정상적으로 즉시 변경됐는지도 알려 주세요.

로그에는 명령의 순서·바이트·반환값이 기록됩니다. 수신 모니터의 내부 이벤트는 이 DLL 프록시에서 기록되지 않습니다. 제조사 EXE/DLL은 결과 폴더에 포함되지 않습니다. 임시 OEM 복사본의 위치는 실행 창에 표시되며, 앱 종료 후 삭제할 수 있습니다.

`capture.cmd`의 실행 정책 변경은 해당 PowerShell 프로세스에만 적용됩니다. 이 패키지는 제조사 프로그램과 장치가 없는 상태에서 전달 함수와 로그 기록을 자동 검증했으며, 실물 정상 Apply 비교에는 위 로그가 필요합니다.
